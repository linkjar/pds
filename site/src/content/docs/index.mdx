<CardGrid stagger>
	<Card title="Running in fifteen minutes" icon="rocket">
		A Compose file with the server and Caddy. Point DNS at the host, fill in
		three secrets, start it. [What you need →](/start/requirements/)
	</Card>
	<Card title="A drop-in for the reference PDS" icon="random">
		The same data directory, the same `PDS_*` variables, the same user id.
		Stop one server, start the other; the relay resumes at its cursor.
		[Switch over →](/operate/migrate-from-reference/)
	</Card>
	<Card title="Small and quick" icon="laptop">
		The server starts in a few megabytes of memory. On a laptop it exported a
		repository of 100,000 records in 167 ms, where the reference server took
		1,385 ms. [Measurements →](https://github.com/linkjar/pds/blob/main/parity/results/perf-reads.md)
	</Card>
	<Card title="An audit log you can check offline" icon="approve-check">
		Every account and admin action is an entry in a hash chain. Checkpoints are
		signed, and a bundle verifies away from the host.
		[Audit log →](/operate/audit-log/)
	</Card>
</CardGrid>
