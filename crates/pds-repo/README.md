# pds-repo

The repository engine: the Merkle search tree, the commit block, CAR v1
files, commits built from writes, export, record proofs, and the checks on
CARs that arrive from elsewhere. It is synchronous and has no I/O of its
own: blocks come in and go out through the `BlockStore` trait. It holds no
keys. The caller passes signing and verifying in as closures; key custody
is pds-identity's and pds-storage's.

## Modules

| Module | Holds |
|---|---|
| `block` | `BlockStore`, `BlockMap`, `MemoryBlockStore`, `Overlay`. |
| `mst` | `node` (the wire form and the key rules), `tree` (`Tree`, `TreeChanges`), `walk` (`Guard`, `read_tree`, `export_blocks`). |
| `commit` | `UnsignedCommit` and `Commit`. |
| `car` | `read_car`, `write_car`, `CarWriter`. |
| `repo` | `Repo` (`load`, `format_init_commit`, `format_commit`, `export`, `record_proof`), `Write`, `CommitData`, `verify_repo_car`, `verify_diff_car`. |
| `error` | `RepoError`, `TreeDefect`, `NodeError`, `SignError`. |

## Place in the workspace

Depends on pds-types. Used by pds-storage (whose `ActorDb` implements
`BlockStore`), pds-sequencer, pds-xrpc, linkjar-pds and pds-sim, and by
`fuzz/` and `bench/`.

## What it needs

Nothing at run time.

## Tests

`cargo test -p pds-repo`. `tests/reference.rs` holds the engine to the
bytes `@atproto/repo` produces; `tests/interop.rs` reads
`interop/firehose/commit-proof-fixtures.json`; `tests/tree.rs` is a
property test against a model; `tests/import.rs` and `tests/proof.rs`
cover invalid trees and record proofs. The fixtures under `tests/fixtures/`
(`reference.json`, `export.car`, the `dag-*.car` files) are regenerated by
`parity/src/tools/repo-fixtures.ts`, which needs Node and pnpm. The
decision for this engine over `rsky-repo` is in
`docs/research/2026-10-12-repository-crate.md`; `bench/` keeps the
comparison.
